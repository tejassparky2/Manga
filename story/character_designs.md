# Character design sheet (art lock)

These are the visual designs used for every panel, by every render worker. **They are PROPOSAL — NOT CANON.** The bible confirms only the traits marked *(canon)*; everything else was chosen to keep the art consistent and needs the author's approval.

The machine-readable tags live in `chapter01/script.yaml` under `characters:`. Every panel prompt expands from them, so changing a design in one place changes it everywhere.

Open design questions for the author:
- **Aoi's gender** is not stated in the bible. Aoi is drawn as a girl as a placeholder.
- **Uniforms** (gakuran and sailor uniforms) are not stated in the bible.

Quality rules applied to every panel:
- **Two characters in one panel:** the model swaps features between them, so these moments use single-character or point-of-view shots.
- **Nothing suggestive:** every character is a high-school student, so the negative prompt rules out suggestive or revealing imagery for all panels.
